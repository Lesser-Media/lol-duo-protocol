# The Duo Protocol

A static, responsive League of Legends duo queue playbook for **Duo One (Mid / ADC)** and **Duo Two (Jungle / Top)**. Desktop uses full-screen chapters with a left navigation rail; mobile uses a scrollable layout. Champion cards, four role-pairing scenarios, a game timeline scrubber and a printable field card work without a framework or build step.

## Run locally

Serve the repository root with any static HTTP server, then open `index.html`. For example:

```sh
npx serve .
```

Vercel can deploy this repository as a **static site** with the root directory and no build command.
